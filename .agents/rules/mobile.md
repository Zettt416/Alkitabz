# Workspace Rules - Alkitab App

## UI/UX Platform Rules
Untuk proyek Alkitab App ini:
- Gunakan skill **`mobile-app-ui-design`** dan **`ui-ux-pro-max`** untuk memastikan antarmuka ergonomis bagi pengguna mobile (layar sentuh / satu jempol) dan nyaman untuk membaca firman Tuhan dalam durasi lama.
- Terapkan prinsip:
  1. **Thumb Zone**: Kontrol navigasi penting di area bawah layar.
  2. **Touch Targets**: Minimal 44×44px untuk nomor ayat dan tombol aksi.
  3. **Readability & Theming**: Tipografi yang sangat nyaman (Serif & Sans-serif, spasi baris leluasa, mode Sepia, Terang, dan Gelap OLED).
